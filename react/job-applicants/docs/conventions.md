#

* `country`: ISO 3166-1 alpha-2
* `state`: country-specific state code
* `address`: UPU S42
* `Phone`:
    * ITU E.164 canonical telecommunications representation
    * ITU E.123 presentation/notation

* `Language`:
    * ISO 639
    * BCP 47 (Language + country/locale)

* Time zone: IANA TZDB
* `gender`: `"male" | "female"` (FHIR)
* Employment data:
    * ISCO-08 (ISCO → What does the person do?)
    * ISIC (What industry/activity does the organization operate in?)

* Education: ISCED
* currency code: ISO 4217
* Accessibility:
	* WCAG 2.1
	* WCAG 2.2
